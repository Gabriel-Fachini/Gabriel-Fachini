## About

I'm a fullstack engineer with 3+ years of professional experience across product, platform, and AI-driven projects. At Toro Investimentos I was the sole developer of an internal engagement platform used by ~700 employees — owning the full product lifecycle from architecture to CI/CD. At Cubbo, I worked in an international engineering team building logistics systems for fulfillment operations in Brazil and Mexico.

My main stack is TypeScript end-to-end (React, Node.js, Fastify, Next.js), with Python for backend services and AI agents. I've shipped production LLM integrations including a Slack RAG assistant and a natural language analytics agent on BigQuery. I care about clean architecture, testability, and building things that actually work in production.

Finishing a B.Sc. in Information Systems at USP (ICMC). Fluent in English.

### 🏆 [Valorize UI](https://github.com/Gabriel-Fachini/valorize-ui)
Corporate employee recognition platform with gamification and a rewards system. Monorepo with **4 independent apps** (employee dashboard, admin panel, multi-tenant backoffice, landing page) managed by Turborepo, deployed on Google Cloud Run with CI/CD.  
`TypeScript` `React 19` `TailwindCSS v4` `TanStack Router` `Shadcn/ui` `Turborepo` `Astro`

---

### ⚙️ [Valorize API](https://github.com/Gabriel-Fachini/valorize-api)
B2B SaaS backend for the Valorize platform. Isolated **multi-tenant** architecture, **RBAC** with 3 roles, coin wallet & voucher system, full audit trail, and test coverage with Vitest.  
`TypeScript` `Node.js` `Fastify` `PostgreSQL` `Prisma` `Supabase Auth` `Vitest` `SonarCloud`

---

### 📺 [AirPlay TV](https://github.com/Gabriel-Fachini/AirPlay-TV)
Android TV app that turns any Android TV device into an **AirPlay receiver** for screen mirroring from Apple devices. Hardware video decoding via MediaCodec, automatic network discovery via mDNS, and a JNI bridge between Kotlin and a C++ core.  
`Kotlin` `C++` `NDK` `Jetpack Compose TV` `MediaCodec` `CMake` `mDNS`

---

### 🔍 [Job Tracker](https://github.com/Gabriel-Fachini/job-tracker)
Local-first app to manage the entire job search lifecycle — structured professional profile, manual job board radar with real-time progress via **SSE**, lead pipeline with AI-powered triage, and application tracking.  
`TypeScript` `Next.js` `SQLite` `Drizzle ORM` `TanStack Query` `Ollama` `OpenAI`

---

### 📊 [Media Traffic AI Analyst](https://github.com/Gabriel-Fachini/media-traffic-ai-analyst)
Natural language analytics agent for media and growth teams. Parses queries in Brazilian Portuguese, routes intent, and executes auditable SQL on **BigQuery** via structured tool calling — the LLM never runs SQL directly. Supports multi-turn conversations with per-thread context.  
`Python` `FastAPI` `LangGraph` `Claude (Anthropic)` `GPT-4` `BigQuery` `Pydantic`

### 🤖 [Health AI Assistant](https://github.com/Gabriel-Fachini/health-ai-assistant)
Conversational agent simulating a medical receptionist for appointment scheduling in natural language. State machine architecture, **multi-LLM** support (OpenAI, Anthropic, Google, Ollama) without code changes, real-time address validation via ViaCEP/Google Maps. **87 tests.**  
`Python` `LiteLLM` `Pydantic` `Tenacity` `Pytest` `Poetry`
